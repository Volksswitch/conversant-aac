# Screenshots to take for the "Getting started" videos

These screens are outside Conversant (the browser, the device, a file picker), so the video program can't capture them. Each list is the screens in the order a new user sees them. The program adds the narration, the voices and the orange rings.

## How to take them

- **Take one screenshot per screen**, in the order listed. If there's an extra screen in between that a new user would see, take that too.
- **Don't crop or mark them up.** The program adds the rings.
- **Check for anything private** before you take a screenshot: your email address, other apps' notifications, open tabs with personal pages. Use a plain wallpaper if you can.
- **Name them in order** (`01.png`, `02.png`, ...) and put them in the folder named under each heading, inside `Videos\screenshots\`. Don't worry about exact names; I'll sort it out.
- **For each one, add a line to a `notes.txt` in the same folder** saying what you tapped next. That tells me where to put the ring.

## 1.2 Installing Conversant

### On a computer (Chrome or Edge) — folder `1.2-computer`
1. conversant.volksswitch.org open in the browser, before installing.
2. The browser's install button or menu item, showing where it is.
3. The "Install Conversant AAC?" box.
4. Conversant open in its own window after installing.
5. The Conversant icon where a user will find it later (Start menu, desktop, or taskbar).

### On an iPad (Safari) — folder `1.2-ipad`
1. conversant.volksswitch.org open in Safari.
2. The Share button tapped, showing the menu.
3. The "Add to Home Screen" screen, with the name filled in.
4. The Home Screen with the Conversant icon on it.
5. Conversant open from that icon.

### On an Android device (Chrome) — folder `1.2-android`
1. conversant.volksswitch.org open in Chrome.
2. The Chrome menu open, showing "Install app" or "Add to Home screen".
3. The confirmation box.
4. The home screen with the Conversant icon on it.
5. Conversant open from that icon.

## 1.4 Keeping your information safe

The parts inside Conversant (Settings, the Data Folder section, the Backup button) are made by the program. These are only the screens in between.

### On a computer — folder `1.4-computer`
1. The Windows folder picker that opens after tapping "Choose Folder", showing where to make a new folder.
2. The new folder made and selected, before confirming.
3. The browser's question asking to let Conversant use the folder, and the button you tapped.

### On an Android device — folder `1.4-android`
1. The Android folder picker that opens after tapping "Choose Folder".
2. A new folder made and selected, before confirming.
3. Android's question asking to let Conversant use the folder.
4. The question Android asks again the next time Conversant opens (it asks every time on Android).

### On an iPad — folder `1.4-ipad`
1. The box that opens after tapping "Backup settings", asking where to save the file.
2. The file saved in the Files app, showing where it went.
