# CR-005: Typed and Express Panel turns are saved as 'control', so the voice harvest never learns from the user's own words

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** high
- **Category:** bug
- **Verdict:** confirmed (skeptic: confirmed; reproducer: reproduced)
- **Location:** `app/js/app.js:3725`
- **Also affects:** `app/js/app.js:2337 (commitExchange hardcodes source)`; `app/js/app.js:3692 (speakAsUserTurn receives source but never forwards it)`; `app/js/app.js:5187 (Express phrase passes 'express')`; `app/js/app.js:3815 (composer Speak relies on default 'composed')`; `app/js/voice-harvest.js:83 (collectExemplars requires 'composed')`; `app/js/review-ui.js:248-252 (fromLabel)`; `app/js/review-ui.js:407 (usedText requires 'express')`; `app/js/review-ui.js:419 (composeUsed requires 'composed')`; `app/js/usage-summary.js:309 (sourceCounts in the weekly report)`; `app/js/app.js:3725 (merged duplicate: Composed sentences and Express phrases are saved as source 'control', so the voice harvest and Conversation Review never see them)`; `app/js/app.js:3725 (merged duplicate: Express Panel phrases and "In my own words" sentences are saved as source 'control' - voice learning and review labels are wrong)`
- **Source:** graph-voice-01, x-contracts-03, live-runtime-02

**What a user notices.** Sentences the user types in "In my own words" are never used to teach the app how they talk, and in Conversation Review a typed sentence or a tapped Express button is described as "a command button" and the Express button they used is not marked. The usage report also shows every typed sentence and Express tap as a command button.

**What is wrong.** speakAsUserTurn(historyText, spokenText, source='composed') is the shared path for the composer's Speak and Express Panel phrases. It uses `source` only for metrics, then calls commitExchange(raw, historyText, -1, { spokenText }) without passing it. commitExchange builds the logged turn with `source: opts.audio ? 'audio' : (index >= 0 ? 'card' : 'control')`, so every composed sentence and every Express phrase is written to the conversation file as source 'control'. No code path anywhere writes 'composed' or 'express' to disk (grep confirms the only literal 'composed' in app/ is the default parameter). This has been true since the source field was introduced in commit b3219e6. Consequences: voice-harvest.classifyTurn returns 'control' for these turns (it trusts a recorded source), so collectExemplars never collects a live composed sentence - Sounds Like Me Phase 2 harvest from real use is silently dead, only Conversation Review 'typed' answers ever become exemplars, and counts.composed is always 0. review-model passes u.source through, so review-ui.fromLabel labels typed turns and Express taps 'a command button', renderPanel never marks the Express button actually used (usedText requires source 'express'), and the composer key's 'used' mark (composeUsed) never shows. The usage summary's 'Where the words came from' and the weekly report misreport the split.

**How it happens.** 1. Choose a data folder, Start, open "In my own words", type "I had a really good time at the game yesterday" and tap Speak. 2. Tap an Express Panel phrase. 3. End the conversation and open conversations/<id>.json: both user turns carry "source": "control". 4. About Me > How I Sound > Read my conversations: the typed sentence never appears among the harvested examples. 5. Open the conversation in Conversation Review: both turns say 'a command button' and no Express button is shown as used.

**Suggested fix.** In speakAsUserTurn change the commit call to `await commitExchange(raw, historyText, -1, { spokenText, source });`. In commitExchange change the source line to `source: opts.audio ? 'audio' : (index >= 0 ? 'card' : (opts.source || 'control')),` (keep 'control' as the default so the repair-of-self and other index -1 callers stay 'control'). Do not change the audio call at app.js:5305 (it already passes opts.audio). Existing files already on disk cannot be repaired; note it in CHANGELOG only if a tester could have been affected in a released build (this has shipped).

<details><summary>Merged duplicate x-contracts-03: Composed sentences and Express phrases are saved as source 'control', so the voice harvest and Conversation Review never see them</summary>

speakAsUserTurn is given the turn's provenance as its third parameter ('composed' by default, 'express' from handleSpeakExpressItem) and uses it for metrics, but it never passes it to commitExchange. commitExchange then derives source from the index alone: any index < 0 that is not audio becomes 'control'. 'control' is reserved for the app's own phrases (Say again, Hold on, Ask them to repeat). Consequences: voice-harvest.collectExemplars only accepts classifyTurn(turn) === 'composed' (or reviewed rewording), so live composed prose - documented as 'the most valuable thing in the log' - is never harvested; review-ui.fromLabel prints 'a command button' and renderPanel's usedId/composeUsed (which require source 'express'/'composed') never mark anything; usage-summary.sourceCounts and the Sheet's 'sources' column report zero composed/express. Present since b3219e6 (Aug 7 2026). Note logs already written cannot be corrected.

Fix as proposed by that reviewer: Thread the provenance through: in speakAsUserTurn change line 3725 to `await commitExchange(raw, historyText, -1, { spokenText, source });` and in commitExchange change line 2337 to `source: opts.audio ? 'audio' : (index >= 0 ? 'card' : (opts.source || 'control')),`. Leave the existing default ('control') for repair-of-self and other index -1 callers.
