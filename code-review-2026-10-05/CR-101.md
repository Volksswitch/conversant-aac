# CR-101: Folder-prompt button text becomes unreadable on hover/after tap

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** accessibility
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/css/styles.css:4335`
- **Also affects:** `app/css/styles.css:2722-2729 (baseline Settings button color var(--ink))`
- **Source:** css-09

**What a user notices.** On About Me, after tapping "Choose data folder" on a touch screen (or pointing at it), the button turns blue while its words stay dark (or light in dark mode), so they become hard to read.

**What is wrong.** `.wv-folder-prompt-btn:hover` changes only the background to --info; the text colour comes from the Settings button baseline (--ink). Default: #1a1a1a on #1565C0 is about 3:1; Dark: #e8eaed on #6faae4 is about 2:1. The rule is outside @media (hover: hover), so on a touch screen the hover sticks after a tap.

**Evidence.**

```
styles.css:4335-4337 `.wv-folder-prompt-btn:hover { background: var(--info); }`
```

**How it happens.** About Me with no data folder chosen, Dark scheme: tap or hover 'Choose data folder' - the label is light grey on light blue.

**Suggested fix.** Add `color: var(--ink-inverse);` to that rule (and optionally move it into the @media (hover: hover) block).

**How to verify the fix.** Manual hover in Default and Dark schemes; label readable.

**Do not break.** Settings hover rules are deliberately allowed outside the media block (Rule 20); only the color needs fixing.

**Design reference.** CLAUDE.md UI Layout Rule 20 and Rule 23

**Verification notes.** The button is rendered inside About Me, which lives in #settingsDialog, so its text color comes from :where(#settingsDialog) button { color: var(--ink) } (styles.css:2722). .wv-folder-prompt-btn:hover (4335) changes only background to --info, giving dark text on #1565C0 (about 3:1) in Default and light text on a light blue in Dark. The rule is outside @media (hover: hover), so it sticks after a tap on a touch screen.
