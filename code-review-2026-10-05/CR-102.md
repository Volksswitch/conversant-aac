# CR-102: "Choice button #N" placeholder text is below text contrast minimum

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** accessibility
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/css/styles.css:5426`
- **Also affects:** `app/js/ui.js:724-728 (renders 'Choice button #N')`; `app/css/styles.css:5426 (merged duplicate: 'Choice button #N' reserved-cell text is below 4.5:1 contrast in Default and Dark)`
- **Source:** css-07, live-visual-08

**What a user notices.** The reserved cells in the Context band that read "Choice button #1" and so on are faint and hard to read, especially for people with low vision.

**What is wrong.** The label colour is the band colour mixed 55% with transparent, drawn over the transparent undefined cell (the dock shows through). Computed for the default scheme: about 2.9:1 against the dock (#e9edf0); in Dark about 3.4:1. Text needs 4.5:1. The theme tests check named token pairs, so a color-mix result applied to text is not covered.

**Evidence.**

```
styles.css:5426-5430 `.ep-btn.ep-choice-slot .ep-text { color: color-mix(in srgb, var(--band-color, var(--band-context)) 55%, transparent); font-style: italic; font-weight: 600; }`
```

**How it happens.** Start with a Context band that has fewer buttons than its four reserved cells: the 'Choice button #1' labels are washed out.

**Suggested fix.** Replace the color-mix with `color: var(--ink-muted);` (italic already says it is a placeholder). If a band tie is wanted, use a mix of at least 85% and verify 4.5:1 in all seven schemes.

**How to verify the fix.** Add the pair (ink-muted on --surface-sunken) to the contrast list in tests/theme.test.mjs if not already present; manually check the label in each scheme.

**Do not break.** Color only - no box property on the cell (Rule 1).

**Design reference.** CLAUDE.md UI Layout Rule 23 (58 contrast pairs, 4.5:1 for words)

**Verification notes.** .ep-btn.ep-choice-slot .ep-text uses color-mix(band-color 55%, transparent) over a transparent undefined cell (styles.css:5426-5430; ui.js:724-728 renders 'Choice button #N'). Computed against the scheme's --surface-sunken: Default 2.94:1, High contrast light 3.08:1, Dark 3.38:1, High contrast dark 4.03:1, Yellow 4.46:1. All under 4.5:1. tests/theme.test.mjs checks named token pairs, so this computed color is not covered.
