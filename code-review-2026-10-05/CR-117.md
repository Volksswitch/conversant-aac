# CR-117: Practice tab: Edit / Make a copy / Delete buttons do not say which scenario they act on

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** accessibility
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/practice-editor.js:137`
- **Also affects:** `app/js/practice-editor.js:118`; `app/js/practice-editor.js:138`; `app/js/practice-editor.js:142`
- **Source:** g-a11y-overflow-07

**What a user notices.** A screen-reader or switch user moving through the practice list hears 'Edit', 'Make a copy', 'Delete' over and over with no scenario name, so it is easy to delete or copy the wrong one.

**What is wrong.** Each row's tool buttons are built by button(label, ...) with only a generic label; the scenario title lives in the neighbouring card button. Out of visual context (Tab order, screen-reader button lists, spoken help aside) the names are identical across rows.

**Evidence.**

```
app/js/practice-editor.js:137 button('Edit', () => goTo({ mode: 'edit', id: s.id })),
app/js/practice-editor.js:138 button('Make a copy', async () => {
app/js/practice-editor.js:142 button('Delete', async () => {
app/js/practice-editor.js:61-63 function button(label, onclick, cls = '') { return el('button', { type: 'button', text: label, class: cls, onclick }); }
```

**How it happens.** Create two scenarios. In Settings > Practice, with a screen reader, Tab past the first card: 'Edit button, Make a copy button, Delete button', then the second row says exactly the same.

**Suggested fix.** After creating each tool button set an aria-label that includes the title, e.g. const t = s.title || '(untitled)'; const b = button('Edit', ...); b.setAttribute('aria-label', `Edit ${t}`); likewise `Make a copy of ${t}` and `Delete ${t}` (and for the built-in 'Make a copy' at line 118). Visible text stays unchanged.

**How to verify the fix.** Manual: Narrator reads 'Delete Doctor visit, button'. Optionally extend tests/ui-standards.test.mjs to assert accessible names of buttons within #practicePanel are unique.

**Do not break.** ui-standards checks consistency of button appearance; aria-label does not change appearance. Keep the danger confirmation on Delete.

**Design reference.** UI-Design.docx §13

**Verification notes.** In practice-editor.js, button() builds generic labels: 'Edit', 'Make a copy' and 'Delete' at lines 137-142, and 'Make a copy' for built-in scenarios at line 118. None carries the scenario title, so the names are identical from row to row. Visible text is unaffected. Delete still asks for confirmation through confirmDanger, and that dialog names the scenario, so a wrong delete is caught at that step.
