# CR-160: The 'how long until the microphone hears something' diagnostic never records anything for paid hearing

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** bug
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/stt.js:681`
- **Also affects:** `app/js/stt.js:692`; `app/js/stt.js:351`; `app/js/stt.js:79`
- **Source:** stt-15

**What a user notices.** Problem reports from people using a paid hearing service always say no listening run heard anything, so a slow-to-start microphone cannot be diagnosed for exactly the tablets that need paid hearing.

**What is wrong.** openSource() returns early for an external source before setting `openedAt` and before `noteListen('sessions')`. afterIngest only records firstHeardMs when `openedAt` is set, so listenTimings() always returns 'no runs heard anything yet' and listenActivity() reports sessions=0 for Deepgram/Azure/REST users.

**Evidence.**

```
stt.js:681-687 `if (externalSource) { ... externalSource.start(); return; }` precedes :688 `noteListen('sessions');` and :692 `if (!openedAt) { openedAt = Date.now(); heardThisRun = false; }`
stt.js:351 `if (heardPartner && !heardThisRun && openedAt) {`
```

**How it happens.** Android tablet on Azure: Troubleshooting system info shows 'firstHeardMs: no runs heard anything yet' after a full conversation.

**Suggested fix.** Move `noteListen('sessions');` and the `if (!openedAt) {...}` line above the `if (externalSource)` block in openSource().

**How to verify the fix.** tests/stt.test.mjs with a fake external source: startListening, deliver text via the wiring onText, assert listenTimings() reports one run.

**Do not break.** none

**Design reference.** none

**Verification notes.** openSource() returns inside `if (externalSource)` before `noteListen('sessions')` and before setting openedAt. afterIngest records firstHeardMs only when openedAt is set. So for paid sources listenTimings() never records a run, and the sessions count stays 0.
