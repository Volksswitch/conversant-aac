# CR-163: A dismissed repeated correction can come back once its first wording ages out of the steer history

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** bug
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/voice.js:203`
- **Also affects:** `app/js/voice.js:184 (MAX_STEERS window)`; `app/js/voice.js:199 (group text = first occurrence in window)`; `app/js/worldview-ui.js:602 (dismiss passes st.text)`
- **Source:** graph-voice-06

**What a user notices.** A user removes a standing correction such as "keep it short" from what the app learned, but after enough later corrections it quietly reappears and starts shaping suggestions again.

**What is wrong.** repeatedSteers groups steers by normalizeSteer (lowercase, punctuation stripped) but represents each group by the exact text of the FIRST steer in the current window, and decides dismissal by comparing that representative's trim().toLowerCase() to the dismissed list. Dismissing stores the representative text verbatim. recordSteer keeps only the last 200 steers, so once the representative entry falls out of the window the group's representative becomes a later variant (e.g. 'keep it short!' instead of 'Keep it short'), which no longer equals the dismissed string, and the dismissed correction is listed and sent to the model again.

**Evidence.**

```
app/js/voice.js:184 `if (p.steers.length > MAX_STEERS) p.steers = p.steers.slice(-MAX_STEERS);`
app/js/voice.js:194 `const gone = new Set(p.dismissed.map((s) => s.trim().toLowerCase()));`
app/js/voice.js:199 `if (!groups.has(key)) groups.set(key, { text: s.text, count: 0 });`
app/js/voice.js:203 `.filter((g) => g.count >= min && !gone.has(g.text.trim().toLowerCase()))`
```

**How it happens.** Reframe with 'Keep it short' twice, then 'keep it short!' twice. About Me > How I Sound shows 'Keep it short' (asked 4 times); remove it. Continue using Reframe until 200+ steers are stored so the two 'Keep it short' entries are trimmed; the group now shows 'keep it short!' (asked 2 times) and is back in the prompt.

**Suggested fix.** Compare normalized keys: `const gone = new Set(p.dismissed.map(normalizeSteer));` and filter with `!gone.has(key)` (keep the key on each group object, e.g. groups.set(key, { key, text, count })). Leave activeExemplars' comparison as it is.

**How to verify the fix.** tests/voice.test.mjs: record 'Keep it short' x2 and 'keep it short!' x2, dismiss the listed text, then drop the first two steers (or simulate by recording 200 other steers) and assert repeatedSteers() is empty.

**Do not break.** The dismissed list is shared with harvested exemplars; do not change how activeExemplars matches.

**Design reference.** voice.js comments on steers and 'the correction must stick' (dismissed list); CLAUDE.md Sounds Like Me Phase 2.

**Verification notes.** Reproduced in node: steers 'Keep it short' x2 and 'keep it short!' x2 group as 'Keep it short' (4); dismissing that text (as worldview-ui.js:602 does via dismissExemplar(st.text)) then recording 198 other steers trims the first two, and repeatedSteers() returns 'keep it short!' (2) again, which buildBlock (voice.js:379) sends to the model as a standing instruction. Trigger requires 200+ recorded Reframe steers and a punctuation/case variant, so it is narrow.
