# CR-189: Bottom Layout 6 ships with two Backspace keys, which the layout document said to resolve before building

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** design-violation
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/keyboard-layouts.js:120`
- **Also affects:** `app/js/express-bands.js:48`
- **Source:** keyboard-11

**What a user notices.** On Bottom Layout 6 there are two identical Backspace keys, and the Express Panel on that layout has one more button position than on other layouts.

**What is wrong.** B6 row 3 ends with BK() and row 4 also contains BK(). The Keyboard Layout Options document lists for B6: 'Watch-outs: Backspace appears on both the letter row and the control row here - pick one in the build.' The build kept both, which also gives B6 33 panel positions where the tests and comments say every layout but B8 has 32.

**Evidence.**

```
keyboard-layouts.js:120-124 `B6: { ... [C('s'), ..., C('z'), BK()], [SH(), PG(), C(','), SP(3), C('.'), BK(), EN()], ]},`; tests/keyboard-layouts.test.mjs comment 'Every other layout offers 32; B8 offers 33'; scripted panelPositionCount(B6) = 33.
```

**How it happens.** Choose Bottom Layout 6; the keyboard shows two Backspace keys.

**Suggested fix.** Decide with Ken which Backspace to keep. If the control-row one goes, replace it with BL(1) (keeps geometry, so no keyguard hole moves) - it then becomes a panel gap rather than a position. Update the test comment if B6 intentionally keeps 33 positions.

**How to verify the fix.** tests/keyboard-layouts.test.mjs: assert each layout has exactly one backspace action.

**Do not break.** Replacing a key with a blank keeps the grid; replacing it with anything that changes spans would move keyguard holes.

**Design reference.** Documents/Conversant AAC Keyboard Layout Options.docx (B6 watch-outs)

**Verification notes.** B6 has BK() at the end of row 3 and again in row 4; the node script counts 2 backspace actions on B6 and 1 on every other layout. The Keyboard Layout Options document's B6 entry says 'Watch-outs: Backspace appears on both the letter row and the control row here - pick one in the build.' Nothing in CLAUDE.md or TODO.md records keeping both. The extra panel position (33 against the test comment's 32) follows from it.
