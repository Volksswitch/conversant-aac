# CR-191: Sound Check replies use British phrasing, and the chosen ones become the user's voice in every prompt

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** design-violation
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/sound-check-items.js:108`
- **Also affects:** `app/js/sound-check-items.js:91 'Quiet one.'`; `app/js/sound-check-items.js:140 'Oh, lovely. Thanks.'`; `app/js/sound-check-items.js:170 'Oh, whereabouts?'`; `app/js/sound-check-items.js:198 'Right, I should let you go.'`; `app/js/sound-check-items.js:250 "Right, I'd better go."`; `app/js/sound-check-items.js:252 'this has been lovely.'`; `app/js/sound-check-items.js:264 "No idea, I'm afraid."`; `app/js/sound-check-items.js:285 'mind you.'`; `app/js/voice.js:310-312 (chosen sentences sent as 'the single most important guide to wording')`; `writing-conventions.json (britishPhrases)`
- **Source:** graph-voice-05

**What a user notices.** The How I Sound questions read as if written in England (a "queue", "lovely", "mind you"), and whichever British-sounding reply the user picks is then used to make all of the app's suggestions sound more British.

**What is wrong.** The forced-choice bank is user-facing text and, more importantly, the chosen candidate is injected verbatim into the system prompt as the strongest wording guide. Several candidates and partner lines use British vocabulary or phrasing that CLAUDE.md lists as tells to remove: 'queue' (American: line/wait), 'lovely' (x2), 'Right,' as a discourse opener, 'whereabouts?', 'mind you', "I'm afraid" as an apology, 'Quiet one.' The American-spelling test only checks spellings and a short list of phrases, none of which match these.

**Evidence.**

```
app/js/sound-check-items.js:108 `partner: "There's a bit of a queue today, I'm afraid.",`
app/js/sound-check-items.js:140 `'Oh, lovely. Thanks.',`
app/js/sound-check-items.js:285 `"It's fine. I was starting to plan my escape, mind you.",`
app/js/voice.js:312 `'Match the length, directness, and level of formality of those examples. They are the single most important guide to wording that you have.'`
```

**How it happens.** Open About Me > How I Sound: the third question shows "There's a bit of a queue today, I'm afraid." A user who picks "Oh, lovely. Thanks." has 'lovely' sent as their own wording example on every generation.

**Suggested fix.** Reword while keeping each item's content constant and its `leads` ordering (authoring rules 2 and the alternation rule): e.g. "There's a bit of a wait today, sorry."; 'Good, thanks. Pretty quiet.'; 'Oh, great. Thanks.'; 'Oh, where did you go?'; 'Well, I should let you go.'; "Okay, I'd better go."; 'I should get going - this has been great.'; 'No idea, sorry.'; "It's fine. I was starting to plan my escape, though." Because stored answers keep the old choice TEXT (voice.js uses `a.choice` directly and the card highlights by text), add a small old->new text map applied in voice.js normalize() to soundCheck[*].choice so existing answers migrate. Add the unambiguous phrases (e.g. 'bit of a queue', 'mind you') to writing-conventions.json britishPhrases.

> **Verifier correction to the fix (takes precedence):** Besides migrating stored choice text in voice.normalize(), check the Sounds Like Me document and any figures/doc text that quote the bank verbatim, and keep each candidate's length/register position so the item still measures its dimension (e.g. 'Good, thanks. Pretty quiet.' must stay the middle-length option). Only add phrases to britishPhrases that have no American reading ('bit of a queue' qualifies; 'mind you' is borderline and should be checked against the documents first so the test does not go red on correct text).

**How to verify the fix.** npm test (tests/american-spelling.test.mjs picks up new britishPhrases entries). Add a test in tests/voice.test.mjs that a profile whose choice is the old 'Oh, lovely. Thanks.' normalizes to the new wording. Manually open How I Sound and read every item aloud as an American speaker would.

**Do not break.** Do not change candidate meaning or the flat/light end ordering of levity items (the levity fix depends on `leads`). Do not re-order items; existing users' progress is keyed by item id.

**Design reference.** CLAUDE.md 'IT IS AMERICAN ENGLISH...' including the third tier (phrasing) and its list of recurring tells ('lovely', 'I'll let you go').

**Verification notes.** The quoted strings are in sound-check-items.js as cited ('queue', 'I'm afraid', 'Oh, lovely. Thanks.', 'Oh, whereabouts?', partner 'Right, I should let you go.', "Right, I'd better go.", 'this has been lovely.', "No idea, I'm afraid.", 'mind you.').
