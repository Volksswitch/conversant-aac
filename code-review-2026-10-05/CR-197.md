# CR-197: Goal buttons reference an undefined --goal-tint token

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** design-violation
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/ui.js:611`
- **Also affects:** `app/css/styles.css:201 (--goal defined, no --goal-tint in any scheme)`; `app/css/styles.css:2348 (.ep-btn background: var(--ep-tint))`
- **Source:** css-10

**What a user notices.** None today; a goal button drawn outside a band would have no background in any color scheme.

**What is wrong.** ui.js sets `--ep-tint: var(--goal-tint)` for goal buttons, but no scheme in styles.css defines --goal-tint. `.ep-btn { background: var(--ep-tint) }` would then be invalid at computed-value time and fall back to transparent. It is masked today only because every goal is drawn in the Flex band, whose rule sets the background from --band-tint.

**Evidence.**

```
ui.js:611 `setColor(b, 'var(--goal)', 'var(--goal-tint)');` ; styles.css palette defines `--goal: #4527A0;` (line 201) and per-scheme --goal, but never --goal-tint.
```

**How it happens.** Any future path that renders a goal without a band class (the band rule's own comment at 2443 says this 'costs nothing to allow') shows a transparent goal button.

**Suggested fix.** Either drop the tint argument (`setColor(b, 'var(--goal)')`, so it falls back to var(--surface-panel)) or define --goal-tint in :root and all six scheme blocks (tests/theme.test.mjs requires every colour token per scheme).

**How to verify the fix.** Run the stylesheet var-reference check (a small script or extend tests/styles.test.mjs to scan app/js for var(--x) references and assert each is defined in styles.css).

**Do not break.** If defining the token, add it to all seven schemes or theme.test.mjs fails.

**Design reference.** CLAUDE.md UI Layout Rule 23 (a token needs a value in every scheme)

**Verification notes.** ui.js:611 calls setColor(b, 'var(--goal)', 'var(--goal-tint)'), and setColor writes --ep-tint from it (ui.js:544-546). grep finds --goal-tint nowhere in styles.css, so --ep-tint becomes invalid at computed-value time and .ep-btn's background: var(--ep-tint) falls back to transparent. It is masked today because goals are drawn in the Flex band, whose band rule sets the background.
