# CR-203: Manual describes four text-size controls; the app has five and the short-version size is undocumented

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** doc-mismatch
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `Documents/Conversant AAC User Manual (Windows Chromebook Mac).docx:343`
- **Also affects:** `Windows manual paragraphs 344-347`; `Documents/Conversant AAC User Manual (iPad).docx paragraph 357`; `Documents/Conversant AAC User Manual (Android).docx paragraph 344`; `app/index.html:402-446`; `app/js/storage.js:1989`
- **Source:** x-defaults-05

**What a user notices.** The manual says text size can be set for four parts of the screen. There is a fifth control, for the short version shown on each response option, and nothing in the manual tells the user it exists or what it does.

**What is wrong.** The CODE is right and the DOCUMENT is wrong. The Text size section has five selects: responseFontSelect ("Response cards - the full response"), hintFontSelect ("Response cards - the short version", added Aug 25 2026 with loadHintFontScale), transcriptFontSelect, composerFontSelect, expressFontSelect. The manual says "four parts" and lists only Response options, Conversation Pane, In my own words and Express Panel.

**Evidence.**

```
app/index.html:411-418  <label for="hintFontSelect">Response cards &mdash; the short version</label> <select id="hintFontSelect" ...>
app/js/storage.js:1989  export function loadHintFontScale() {
Windows manual para 343: "“Text size” controls how large the lettering is on four parts of the screen ... Each of the four offers four sizes"
```

**How it happens.** A user who finds the short labels hard to read looks in the manual for a way to enlarge them and finds none, although the control exists.

**Suggested fix.** Edit the three manuals: change "four parts of the screen" to "five parts of the screen" and "Each of the four offers four sizes" to "Each offers four sizes". Split the first bullet into two: "Response options, the full wording — ..." and "Response options, the short version — the short label shown on a response option, sized separately so you can make whichever one you read first the larger." Quote the labels to match the screen (or the renamed labels, if the card-terminology finding changes them).

**How to verify the fix.** python scripts/doc-tests/check-docs.py on each edited manual; compare the list against app/index.html lines 402-446.

**Do not break.** None in code. Follow the sync-docs backup rule and the tracked-changes block.

**Design reference.** CLAUDE.md storage.js 'The AI's short label for a response, sized on its own (Ken, August 25 2026)'

**Verification notes.** index.html has five text-size selects including hintFontSelect ('Response cards — the short version', line ~412); the Windows manual para 343 says 'four parts' and 'Each of the four' with bullets 344-347 listing four. Same in iPad 357 and Android 344.
