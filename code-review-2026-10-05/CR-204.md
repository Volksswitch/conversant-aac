# CR-204: Manual uses British 'tick' for the joke-voices checkbox

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** doc-mismatch
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `Documents/Conversant AAC User Manual (Windows Chromebook Mac).docx:369`
- **Also affects:** `app/index.html:646`
- **Source:** x-defaults-07

**What a user notices.** The manual tells the reader to "tick" a box; the house rule is to say "check", because an American reader looking at a checkbox may hunt for something to tick.

**What is wrong.** The CODE is right and the DOCUMENT is wrong. CLAUDE.md's American-English rule singles out 'tick the box' as misleading vocabulary and requires 'check'. The Voice row says 'unless you tick Show this device’s joke voices', and the control name is also not quoted, contrary to the quotes convention.

**Evidence.**

```
Windows manual para 369: "...which are hidden unless you tick Show this device’s joke voices."
app/index.html:646  <input type="checkbox" id="showNoveltyVoicesInput"> Show this device's joke voices (Bahh, Boing, Zarvox…)
```

**How it happens.** Reader of section 6.3 Voice row.

> **Verifier correction to the trigger:** Affects all three manuals: Windows para 369, iPad 383, Android 370.

**Suggested fix.** Change to: "...which are hidden unless you check “Show this device’s joke voices”." Check the iPad and Android manuals' equivalent row for the same word. Consider adding the phrase "unless you tick" / "you tick" to britishPhrases in writing-conventions.json only if it has no innocent American reading.

**How to verify the fix.** python scripts/doc-tests/check-docs.py; grep the dumped manual text for " tick".

**Do not break.** Leave innocent uses (a clock tick) alone if any.

**Design reference.** CLAUDE.md 'IT IS AMERICAN ENGLISH, NOT AMERICAN SPELLING' (tick vs check)

**Verification notes.** Windows manual para 369 says 'unless you tick Show this device’s joke voices' (unquoted control name). Same sentence in iPad para 383 and Android para 370. CLAUDE.md's American-English rule names 'tick the box' as the misleading vocabulary case.
