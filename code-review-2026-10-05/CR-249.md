# CR-249: Deleting a sound button in the Express editor asks to delete "this button" instead of its name

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** ui-inconsistency
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/express-editor.js:218`
- **Also affects:** `app/js/express-editor.js:181`
- **Source:** live-runtime-08

**What a user notices.** When the user deletes a sound button, the warning says "this button" will be removed rather than naming the sound, so they cannot confirm they picked the right one.

**What is wrong.** labelOf() returns `item.text || item.name`, but audio items keep their face in `item.label`. removePicked therefore falls back to the literal 'this button' and the confirm body reads `"this button" will be removed...`.

**Evidence.**

```
app/js/express-editor.js:218  return String(item.text || item.name || '').trim();
app/js/express-editor.js:181  const label = labelOf(list[i]) || 'this button';
app/js/express-editor.js:145  const item = { id: makeId(), type: 'audio', label: '', kind: AUDIO_KIND.SOUND };
Runtime: delete dialog read '"this button" will be removed, and every button after it moves up one place.'
```

**How it happens.** Settings > Express Panel and Keyboard > Always > Add a sound, give it a label, select it, tap the X tool: the danger card names 'this button'.

**Suggested fix.** In labelOf add `item.label` to the fallback chain: `return String(item.text || item.label || item.name || '').trim();` and in removePicked build the body without quotes when falling back (e.g. `label ? `"${label}" will be removed` : 'This button will be removed'`).

**How to verify the fix.** Manual as above with a labelled sound; a blank phrase should read 'This button will be removed...' without stray quotes.

**Do not break.** labelOf is also used for partner faces; keep the relationships.displayName branch first.

**Design reference.** CLAUDE.md standing rule 'Confirm before destroying significant work' (confirmDanger)

**Verification notes.** labelOf (express-editor.js:218) returns item.text || item.name, but audio items store their face in item.label (addAudio at 145 creates { type: 'audio', label: '' }). removePicked therefore falls back to 'this button', and the confirm body renders '"this button" will be removed...'. The suggested fix (add item.label to the chain, drop the quotes on the fallback) is correct.
