# CR-261: 'Show conversations from any time' button is drawn at hint-text size, smaller than every other Settings button

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** ui-inconsistency
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/review-ui.js:864`
- **Also affects:** `app/js/review-ui.js:841-865 (olderNote is a .setting-hint paragraph)`; `app/css/styles.css:3711-3716 (.setting-hint font-size 0.8rem)`; `app/css/styles.css:981-984 (dialog buttons inherit font-size)`
- **Source:** live-visual-10

**What a user notices.** On Conversation Review, the button that reveals older conversations has smaller lettering than all the other buttons in Settings.

**What is wrong.** The button is appended inside the <p class="setting-hint review-older"> note. Settings buttons inherit font-size (:where(#settingsDialog) button { font-size: inherit }), so it takes the hint's 0.8rem (11.7px) instead of the panel's 14.6px. tests/ui-standards.test.mjs never sees it because it only renders when older conversations exist in a data folder.

**Evidence.**

```
app/js/review-ui.js:858-864:
        olderNote.textContent = `Older conversations are hidden (${logs.older}, real and practice together). `;
        const more = document.createElement('button');
        ...
        olderNote.appendChild(more);
Measured: BUTTON 'Show conversations from any time' fontSize 11.68px; other Settings buttons 14.6px.
```

**How it happens.** With conversations older than a week in the data folder: Settings > Conversation Review > Saved conversations shows 'Older conversations are hidden (13, …)' followed by a small-text button.

**Suggested fix.** Append the button as a sibling after the note (panel.appendChild(more) after olderNote, hiding/showing it with the note), or give it an explicit font-size: var(--panel font) via a class (e.g. .review-older button { font-size: 0.9rem; } matching other Settings buttons).

**How to verify the fix.** Browser check with seeded older conversations: the button's computed font-size equals that of #pasteApiKeyBtn.

**Do not break.** none

**Design reference.** UI-Design.docx §13 'One size for one kind of control across every tab'.

**Verification notes.** review-ui.js:858-864 appends the button inside <p class='setting-hint review-older'>. .setting-hint sets font-size 0.8rem (styles.css:3711-3716), and Settings buttons inherit font-size through the rule at 981, so this button is smaller than the panel's other buttons. It only renders when older conversations exist, which is why the UI-standards test never sees it.
