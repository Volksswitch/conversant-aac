# CR-264: Restart confirmation does not mention that the general goal list is also deleted

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** ui-inconsistency
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/worldview-ui.js:443`
- **Also affects:** `app/js/relationships.js:257-263 (resetAll clears g.goals, the 'Goals For Any Conversation' list)`
- **Source:** worldview-10

**What a user notices.** The 'Clear everything?' warning lists answers, people, places and how-you-sound, but it also silently wipes the 'Goals For Any Conversation' list.

**What is wrong.** onRestart calls rel.resetAll(), which empties people, edges and the graph-root `goals` array (the general goal list added September 2026). The confirmDanger body was not updated, so a destructive action deletes something the warning does not name.

**Evidence.**

```
app/js/worldview-ui.js:443: body: 'This permanently deletes every answer, all the people you have added, all the places you have added, and everything the app has learned about how you sound. This cannot be undone.',
app/js/relationships.js:258-261: g.people = []; g.edges = []; g.goals = [];
```

**How it happens.** Add two goals under About Me > Goals For Any Conversation. Tap Restart and confirm. The goal list is empty, although the warning never mentioned goals.

**Suggested fix.** Extend the body text: '...all the places you have added, your goals for any conversation, and everything the app has learned about how you sound.'

**How to verify the fix.** Manual: read the Restart dialog text.

**Do not break.** Keep confirmDanger (not window.confirm).

**Design reference.** CLAUDE.md 'Confirm before destroying significant work'.

**Verification notes.** onRestart's confirmDanger body (worldview-ui.js:443) names answers, people, places and how-you-sound. rel.resetAll (relationships.js:257-263) also sets g.goals = [], which is the 'Goals For Any Conversation' list, and the warning never mentions it.
