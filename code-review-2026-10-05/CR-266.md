# CR-266: Every topic note is shown with a padlock, including notes that have nothing to do with privacy

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** ui-inconsistency
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `app/js/worldview-ui.js:1566`
- **Also affects:** `app/js/worldview-ui.js:336-339 (the home list correctly shows a lock only on all-private modules)`; `app/data/worldview-questions.json:559 (B1 note)`; `app/data/worldview-questions.json:777 (B2 note)`; `app/data/worldview-questions.json:840 (B4 note)`; `app/data/worldview-questions.json:1140 (B6 note)`
- **Source:** worldview-07

**What a user notices.** The pages 'What I'm Like', 'Humor & Playfulness', 'What Matters to Me' and 'How I Am With Different People' open with a padlock beside their introduction, suggesting the answers are private when they are not.

**What is wrong.** renderModule prefixes every module note with the lock emoji. The comment says this is for the 'Private by default' notice on A5, but notes exist on A5, A6, B1, B2, B4, B5 and B6. For B1/B2/B4/B6 all fields are shareable and the notes describe purpose, not privacy, so the lock is misleading and disagrees with the home list, which shows the lock only on modules whose every field is private.

**Evidence.**

```
app/js/worldview-ui.js:1564-1567:
    // Show module-level note if present (e.g. the "Private by default" notice on A5)
    if (mod.note) {
        contentEl.append(el('p', { class: 'wv-module-note', text: '🔒 ' + mod.note }));
    }
B6 note: "Most people talk differently to a close friend than to a doctor. ..."
```

**How it happens.** Open Settings > About Me > 'How I Am With Different People'. The intro reads '🔒 Most people talk differently...'.

**Suggested fix.** Prefix the lock only when the module carries private fields, e.g. `const anyPrivate = mod.fields.some((f) => f.defaultPrivacy === 'private'); const text = (anyPrivate ? '🔒 ' : '') + mod.note;`. (A5, A6 and B5 keep the lock.)

**How to verify the fix.** Manual: open each module; only Contact & Logistics, Health & Safety and Beliefs & Convictions show the padlock.

**Do not break.** none

**Design reference.** CLAUDE.md Worldview privacy model (three levels).

**Verification notes.** renderModule always prefixes the module note with the lock emoji (worldview-ui.js:1564-1566). The registry has notes on A5, A6, B1, B2, B4, B5 and B6. B1, B2, B4 and B6 have shareable fields and notes that say nothing about privacy. The home list shows the lock only when every field is private, so the two screens disagree.
