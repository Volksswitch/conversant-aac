# CR-268: Spoken help for the Conversation tab still says it covers what the app says while choosing

Part of the [October 5, 2026 code review](README.md). Read its instructions before fixing.

- **Severity:** low
- **Category:** ui-inconsistency
- **Verdict:** confirmed (skeptic: confirmed)
- **Location:** `settings-help.json:40`
- **Also affects:** `app/index.html:801-873`; `app/index.html:874`; `settings-help.json:204`; `settings-help.json:214`
- **Source:** x-defaults-09

**What a user notices.** Asking for help on the Conversation tab says it sets what the app says while you choose, but those settings have moved to their own Placeholders tab, so the user is sent to the wrong place.

**What is wrong.** The Conversation tab now holds Saving conversations, Response suggestions and Listening; the placeholder timings live on the separate Placeholders tab (index.html 874). The tab-level spoken help was not updated. In the same file, two paste-button entries read 'a OpenAI' and 'a ElevenLabs', which are spoken aloud.

**Evidence.**

```
settings-help.json:40  "conversation": "How the app listens, how many responses it offers you, and what it says while you are choosing."
settings-help.json:204  "pasteOpenaiKeyBtn": "Pastes a OpenAI key you have already copied."
settings-help.json:214  "pasteElevenlabsKeyBtn": "Pastes a ElevenLabs key you have already copied."
```

**How it happens.** Settings > arm ? > tap the Conversation tab: the description mentions placeholders, which are not on that tab.

**Suggested fix.** settings-help.json: conversation -> "Whether conversations are saved, how many responses you are offered and how they are shown, and how the app listens."; pasteOpenaiKeyBtn -> "Pastes an OpenAI key you have already copied."; pasteElevenlabsKeyBtn -> "Pastes an ElevenLabs key you have already copied." Then run `node scripts/apply-settings-help.mjs`.

**How to verify the fix.** npm test (settings-help drift test); arm ? and tap the Conversation tab.

**Do not break.** Keep entries under the 35-word cap enforced by tests/settings-help.test.mjs.

**Design reference.** CLAUDE.md UI Layout Rule 17 (spoken help)

**Verification notes.** settings-help.json:40 says the Conversation tab covers 'what it says while you are choosing', but placeholder settings are on a separate Placeholders tab. Lines 204 and 214 read 'a OpenAI' and 'a ElevenLabs', which are spoken.
