Conversant switch access prototype

Anywhere on this page except the settings panel, the left mouse button is switch 1 and the right mouse button is switch 2. Space and Enter do the same. With three switches, the middle mouse button is switch 3, which moves back; keys 1, 2 and 3 also work. Pick an example in the settings panel, or change the settings. Nothing here uses the real AI: the partner and the response options are made up, and the AI's reply is a fixed wait.

For a switch interface that sends key presses. Tap “Set”, then press the key (or the switch). Setting a key leaves the mouse buttons working as switches, so a supporter can still help with a mouse; uncheck the box for an interface that sends both a key and a click, which would count one press twice. How the scan moves

One line is for the whole screen, all or nothing: options and New 4, the whole Express Panel ignoring bands, “In my own words”, then the Command Bar. In “In my own words” it is every key in turn.

Scan method

One switch: automatic, inverse or hold to move. Two or three switches: step. In step scanning, holding a button that moves keeps the highlight moving (racing).

Seconds per stop
Top speed while a switch is held (seconds per stop)
Speeding up while held

While a switch is held, the highlight starts at “Seconds per stop”, and each stop then comes a little sooner until it reaches the top speed. Set a top speed slower than “Seconds per stop” and holding slows it down instead.

Tap or hold

Step: holding a button that moves keeps the highlight moving once the press is a hold. Hold to move: the first stop comes when the press becomes a hold, then the scan speeds up as set above, so a short hold moves one stop.

Settings take effect at once and restart the scan. “Pause”, at the end of the Command Bar, stops the scan; hold a switch for 2 seconds to start it again. “Settings” on the Command Bar is skipped. “End” and “Don’t save” always ask for a second press.
