Switch Control screen test

Each "Settings" button opens the same panel a different way. A to E change the page that is showing; F and G load a new page, and F loads this whole page again. With Switch Control on, open each one and note whether the highlight moves into the panel at once, or keeps going around the buttons behind it. Then close it and try the next. Scroll test H is a different problem: a list that scrolls.

Scroll test H

The tabs are in a box that scrolls, like Conversant's Settings tabs, and the buttons below it stand in for the Express Panel. Scroll the page so the box and the buttons are on screen. Then move the highlight down the tabs: does it go onto tabs hidden below the box, and does the box scroll to show them? The lines at the bottom show what this page is told. A red outline marks the page's keyboard focus.
