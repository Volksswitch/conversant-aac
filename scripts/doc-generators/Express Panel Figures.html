Always band the words that stay in the same place forever. First, so nothing can shift them. Extra phrases are reached with the band's own More button.
Context band the buttons that never speak: who the partner is, where the user is, the topic, and how they feel.
Flex band the user's goals (→), then phrases suited to the topic, partner and place selected above. Flows around the compose key.

What puts a button in a band is where its content comes from. The user supplies who, where, what about and how they feel in the Context band; the Flex band holds what depends on those choices. Feeling does not fill the Flex band. The order is by which band must not move, not by importance.
One background color per band. Inside the Context band a small mark says the kind of button: ● partner, ▲ place, ◆ topic, ■ feeling. The mark is a setting; this is the default.

"Is it mild, moderate or severe?" The choices take the far end of the band, in solid color — immediate and temporary, and this is where the conversation is right now. Nothing that speaks has moved, and nothing the user has learned well is hidden: the far end is where the feelings sit, which are expected to be the least used thing on the panel, while the partner buttons at the front are never covered. A question asking for a number puts one button labeled 123 in the same place, styled exactly the same way — the two are the same kind of thing and live for the same single exchange, so they differ in nothing at all.

How the Flex band is filled — most likely first, and never blank

The user lists each partner's phrases in the order they are likely to want them, and does the same for each place. Filling runs from the most specific list to the least — this partner in this place, then this partner anywhere, then anyone in this place, then the general set — until the room runs out. A phrase listed in two of them is shown once. All four are made the same way, by picking a partner and a place from two lists that also offer Anyone and Anyplace, so the general set is simply Anyone plus Anyplace. When more phrases are listed than fit, the band's last position becomes its own More button. Always phrases never come into this band.

No button can be blank, because the general set always has more phrases than the room left over. The most likely thing is always first, which is the only ordering promise made — and it is one the user controls directly, by ordering their own lists. What does not fit on the first set is the least likely of the general phrases, one tap away behind More.

Setting it up: the panel is the editor

The live panel sits beside Settings and is tappable there. Tapping a button selects its row in the list below. The bands are tinted so it is obvious which one a button belongs to, and the two dropdowns above say which situation is being edited — the part that must never be ambiguous. Each row carries the words, how they should be said, and a speaker to hear it before settling on a spelling.
